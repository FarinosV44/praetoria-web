# Servicios (#5)

Generado por `node scripts/servicios/matriz.mjs` a partir de `src/lib/servicios.ts`. **No editar a mano.**

Un servicio es algo concreto que el despacho hace, con un siguiente paso. Las páginas de área los agrupan y los artículos enlazan al que corresponde. El botón de cada servicio abre `/contacto/?servicio=<id>`, que deja preelegidos el área y el asunto (se pueden cambiar). El id se guarda con la consulta: no debe cambiarse.

**Texto ampliado** (qué revisamos, proceso, documentación, preguntas y normas citadas): lo redacta la web a partir de lo ya publicado y de fuentes oficiales, y queda *pendiente de revisión* hasta que el despacho lo valide (`revision: 'revisado'`).
